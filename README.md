# Predictive-Modelling-on-a-Web-Scraped-Data-with-a-Power-BI-Dashboard
Built an end‑to‑end predictive modeling project using real‑world scraped data. Designed Python scripts to collect 1,000+ records, cleaned and preprocessed data, performed EDA, and applied ML models for predictive insights. Evaluated performance and built a Power BI dashboard to deliver business‑friendly recommendations.
